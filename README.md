# Time Machine Warning Line

A one-line warning label for a time machine, written for the make.fun bounty "Funniest Time Machine Warning Label". The program writes a single deadpan safety notice to `/output/entry.txt` — 120 characters or fewer, with the duplicate-self hazard turned into the punchline.
